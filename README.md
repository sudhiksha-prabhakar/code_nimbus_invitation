# Rahul & Ramya — Engagement Invitation

An interactive, responsive digital engagement invitation web application built with React and Vite.

## Features

- **Interactive Cover Page:** Elegant splash screen with animated bride & groom illustrations and smooth transition.
- **Live Countdown:** Dynamic countdown timer tracking the days, hours, minutes, and seconds until the celebration.
- **Bride & Groom Spotlight:** Interactive 5-second single photo carousel displaying the bride and groom.
- **Event Schedule & Timeline:** Visual timeline of engagement ceremonies and event details.
- **Interactive Wishes Section:** Digital guestbook wish section and form for sending blessings to the couple.
- **Venue & Map Links:** Detailed venue information for Royal Orchid Convention Center with Google Maps integration.
- **Meet the Families & Our Story:** Special story section and family member introduction tabs.
- **Photo Gallery:** Dedicated photo gallery album with interactive upload feature.
- **Audio & Quick Access:** Ambient background music player and floating quick-contact controls.

## Development & Setup

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Run Locally

```bash
npm install
npm run dev
```

### Build for Production

```bash
npm run build
npm run preview
```
